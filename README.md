# Jolé · Tienda de tejidos típicos

Sitio estático de la tienda Jolé (trajes típicos de Guatemala). Versión de demostración: productos, precios y regiones son ejemplos y no se procesa ningún pago.

Se publica tal cual con GitHub Pages desde la rama `main` (raíz). No requiere compilación; el visor 3D carga `three@0.160.0` desde jsDelivr.
